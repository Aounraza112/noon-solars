# NOON SOLARS Website

## Files
- index.html — main website
- style.css — design and responsive styling
- images/ — add your logo and photos here

## Images
The NOON SOLARS logo has already been added as `images/logo.jpg`.
You can add/replace `hero.jpg` and project/gallery photos later.

For the gallery/project photos, replace the placeholder blocks in `index.html` with:
<img src="images/your-photo.jpg" alt="Solar Project">

## Publish on GitHub Pages
1. Create a GitHub account.
2. Create a new repository, e.g. `noon-solars`.
3. Upload `index.html`, `style.css`, and the `images` folder.
4. Open repository Settings → Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select `main` and `/ (root)`, then Save.
7. GitHub will provide your live website link.
